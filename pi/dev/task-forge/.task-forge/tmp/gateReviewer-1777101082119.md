## Summary

Converted `index.ts` from a monolithic command handler into a thin integration shell that follows **parse → delegate → append → derive → render**.

### Changes Made

**`tests/integration/index-shell-delegation.structural.test.ts`**
- Fixed the test to compile with standalone `tsc --noEmit` by replacing the default `assert` import with `import * as assert from "node:assert"` and replacing `import.meta.dirname` with `process.cwd()`-based resolution.

**`index.ts`**
1. **Added V2 command service imports** for all shell commands:
   - `execute`, `status`, `resume`, `blocker`, `pause`, `abort`, `cost`, `models`, `config`, `help`
2. **Added `applyCommandEvents` helper** that appends returned events via V2 storage and re-derives the snapshot, encapsulating the **append → derive** lifecycle step.
3. **Refactored every command handler** to delegate transition logic to V2 services:
   - **Simple queries** (`status`, `help`, `config`, `cost`, `models`) now call their respective V2 command services and render the returned data.
   - **Lifecycle commands** (`pause`, `resume`, `abort`) use `pauseCommandService`, `resumeCommandService`, `abortCommandService` for transition decisions, then `applyCommandEvents` to persist and derive.
   - **Execute** composes `resumeCommandService` (when paused) with `executeCommandService` for the approval/execution transition check, removing inline `canExecute`-equivalent logic.
   - **Blocker** delegates list, retry, patch-validation, and resolve operations to `listBlockersCommandService`, `retryTaskCommandService`, `patchValidationCommandService`, and `resolveBlockerCommandService`.
