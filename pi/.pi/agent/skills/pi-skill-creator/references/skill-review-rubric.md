# Skill Review Rubric

Use this rubric to review an existing skill.

## 1. Compliance
- frontmatter valid
- name matches folder
- description present
- structure valid for pi

## 2. Triggering
- description specific
- covers realistic user phrasing
- neither undertriggers nor overtriggers too badly

## 3. Clarity
- instructions understandable
- sections logically ordered
- references used well
- examples actually help

## 4. Portability
- minimal harness assumptions
- paths are relative where possible
- setup/dependencies are explicit
- no hidden environment-specific magic

## 5. Maintainability
- `SKILL.md` not overloaded
- references are split sensibly
- scripts are only used when valuable
- future edits are straightforward

## Suggested output format for reviews

```markdown
# Skill Review

## Summary
Short verdict.

## Strengths
- ...

## Issues
- ...

## Recommended changes
1. ...
2. ...
3. ...
```
